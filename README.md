## Core Focus Areas

## Featured Repositories

### [AQUASPECT](https://github.com/Adel-333/AQUASPECT)
Earth observation intelligence pipeline translating hyperspectral (Tanager-1, 426 bands) and multispectral (Sentinel-2) data into water quality metrics, baseline median models, and statistical anomaly detection.

### [GAAC](https://github.com/Adel-333/GAAC)
Full-stack examination platform and tournament engine for the Global Astronomy & Astrophysics Challenge. Features proctoring event telemetry, team authentication, dynamic scoring pipelines, and verifiable certificates.

### [king-pbh-validation](https://github.com/Adel-333/king-pbh-validation)
Scientific codebase implementing two-component King models (stars and primordial black holes) paired with direct N-body leapfrog integration in REBOUND for velocity dispersion profile validation.

### [astro-workshop](https://github.com/Adel-333/astro-workshop)
Web application for the AstraVale Astrophotography Workshop, featuring real-time Three.js starfields, interactive curriculum breakdowns, and attendee onboarding.

### [Chem-Trace](https://github.com/Adel-333/Chem--Trace)
Sensor telemetry and chemical byproduct monitoring system utilizing calibrated MQ-135 and MQ-2 sensor arrays for gas concentration analysis.
